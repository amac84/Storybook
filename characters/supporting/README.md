# Supporting characters

The family tree lives in `characters/family.md`.
Household parents: `mamma.md`, `dad.md`.
Everyone else: `extended-family.md` until a person needs their own file.

One file per recurring extra who needs more than a tree row:

`characters/supporting/<id>.md`

Incidental one-book names do not need a file. If they might return, add proposed canon on the book and promote after approval.

## File skeleton

```markdown
# <Name>

```yaml

name:
role: supporting
status: placeholder | approved

```

## Do not

- Stereotype the funny neighbour, the wise old sailor, or the scoldy adult.
- Let a supporting adult solve the central problem.
- Invent a major recurring protagonist here. That is an escalation.
